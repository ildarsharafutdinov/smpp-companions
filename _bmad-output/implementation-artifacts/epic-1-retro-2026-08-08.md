## Goal Achievement

**Largely achieved, with two important caveats.** The goal was a PURE, extractable,
conformance-proven + fuzz-hardened SMPP 3.4 codec + `companion.*` fail-fast config + a Spring Boot
substrate with a phase-ordered graceful-shutdown orchestrator.

- **1.1** — two-module Gradle substrate + CI gates (JDK 25 relaxed to an unpinned environment
  precondition after the vendor-pin was lifted).
- **1.2** — SMPP 3.4 codec, genuinely conformance-proven field-by-field against a jSMPP 3.0.2
  oracle (`CODEC-031`), golden-corpus backed, fuzz/jqwik-hardened, JMH-anchored, runtime purity
  held at `{io.netty}`+JDK.
- **1.3** — config fail-fast matrix, exhaustive role×mode + TLS + secrets + AD-30, **but
  completeness arrived in two passes** (a HIGH NPE false-RESOLVED + 14 silently-dead guards closed
  only by the post-merge `fc2c2fc` hardening).
- **1.4** — compile-time null-safety gate on both modules with a mutation-resistant AC4 control.

**Net:** the substrate Epic 2 mounts is real and the invariants are mechanically enforced *where
they bite* — but a meaningful fraction of the safety net only became trustworthy after post-merge
audits, and several items are explicitly deferred onto Epic 2. The goal is met at `master`; the
confidence in it was earned late and unevenly across stories.

## Challenges & Growth Areas

**1. Test efficacy — tests that stay green but do not bite when the guard is removed.** The single
most pervasive Epic 1 struggle, in four shapes:
- **Null-vs-blank binding trap (1.3):** tests remove the config key (Spring coerces missing → null)
  instead of binding the blank/invalid value the guard exists for → green whether the guard lives.
  Killed **14 / 33** config guards.
- **`RecordingAllocator`-bypass (1.2, 3×):** one `writeInbound(Unpooled.buffer())` short-circuits
  `MERGE_CUMULATOR` so the bounded-memory assertion holds tautologically for any decoder.
- **No-op / tautological tests (1.1):** `TestKit` controls invoked the gate task directly, so
  deleting the `check`-wiring left every control green (the `RELAY-018` silent-bypass).
- **Missing `isOpen()` assertions (1.2):** `ctx.close()` on reject paths had zero close assertions.

**2. Stale / over-optimistic records** — `RESOLVED` markers and patch summaries that did not survive
to merge in their stated form. From the headline false-RESOLVED to benign-but-misleading count
snapshots ("8 patches → 22 tests" superseded to 20; two patches not surviving as stated).

**3. Spec / catalog errors caught only at implementation time** — load-bearing factual errors in
planning artifacts (`bind_transceiver=0x0F`; the nonexistent `com.uber.nullaway` plugin id — NullAway
is an Error Prone check; "OWASP runs in the build" — it's a CI lane). Each forced in-flight
reconciliation against the SMPP PDF / primary source. One correction was only 2-of-3
(`CODEC-017:169` still carries `0x0F`).

**4. In-flight design reversals** — framer reversed to an `LFBD` subclass (invalidating signed-
`getInt` comments); `companion.*` redesigned from flat scalars to a tree; AC9 fail-fast migrated to
Spring `@Validated`/`@NotNull`. None fatal; each caused rework + stale-reference cleanup.

**5. Same-model self-review efficacy risk** — `glm-5.2` authored and reviewed every story,
violating the fresh-context + different-LLM recommendation. Compensated consistently with adversarial
subagents and still surfaced real issues — but the structural risk was carried throughout.

## Key Insight — The False-RESOLVED / Silent-Bypass Systemic Finding

**FALSE-RESOLVED is a recurring failure mode, not a one-off — and it shares a single root cause
with the silently-dead-guard sibling.**

Headline instance: `deferred-work.md` marked *"`validateTls` null-guards `tls`/`protocols` before
deref — RESOLVED 2026-08-03 (T1)"* but this was **false at the `78e4ff6` merge**. The ledger credited
T1 for a guard T1 had *removed*; the validator NPE'd on an omitted `companion.tls.*` block. It stood
unchecked until the 2026-08-04 review flagged it HIGH. **Root cause:** a `@ConstraintValidator` runs
in the same Hibernate pass as `@NotNull` — *before* field guarantees hold — so helpers cannot assume
non-null params. The ledger's own 2026-08-06 annotation now calls it "a re-occurrence of the
false-RESOLVED failure mode."

The same root produced the 14 silently-dead guards via the null-vs-blank trap. **The corrective
discipline, proven by the `fc2c2fc` audit:** a fault-injection / mutation pass that proves
**RED-on-neuter** is the *only* reliable proof a guard is alive. Every `RESOLVED` marker must be
re-verified against the actual codebase at merge time AND backed by a test that binds the specific
non-null-but-invalid value and goes red when the guard is removed. A marker credited to an earlier
task without re-verification is untrusted.

## Discoveries That Shape Epic 2 (no replan — direction is right; bake into stories at create-time)

1. **The codec is bind-only by design (AD-3).** Every non-bind PDU is an opaque framed ByteBuf.
   Epic 2's relay handles the full mix as opaque splice units; the A-1 smoke test exercises exactly
   that. No typed surface to lean on for non-bind PDUs.
2. **Header-only non-ROK `bind_resp` is strict-rejected + closed.** A real SMSC frequently returns a
   bare denial with no body — the relay treats it as "connection failed," losing the typed denial
   code. Epic 2 diagnostics must account for it.
3. **Password `AsciiString→char[]` is a genuine Epic 2 seam.** AD-12's `BindCredential` takes
   `char[]`; the codec hands `AsciiString`; a single `toString()` caches a surviving `String`. The
   relay/adapter must never `toString()` the password; CODEC-024 P2 is the durable fix.
4. **Catalog literals can be wrong on load-bearing values** — verify against the SMPP 3.4 PDF + an
   independent oracle before coding.
5. **`jqwik @Property` must carry NO Jupiter annotations** (`@DisplayName`/`@Tag`) — silent skip,
   green build. Class-level only.
6. **Structural config trees retire invariants by construction** (the `SEC-051` win) — prefer making
   bad states unrepresentable.
7. **`@ConstraintValidator` runs before `@NotNull` field guarantees hold** — every helper needs its
   own null guard (root of the headline false-RESOLVED).
8. **No `com.uber.nullaway` Gradle plugin id exists** — NullAway is an Error Prone BugChecker on the
   `errorprone` configuration; the `net.ltgt.errorprone` plugin is a separate version number;
   NullAway 0.13.8 JSpecify support is incomplete for library-method return propagation.
9. **`@NullMarked` does NOT propagate to sub-packages** — Epic 2's `relay/`, `security/`,
   `observability/` each need their own `package-info.java`.
10. **`RecordingAllocator`-bypass is a named anti-pattern** — feed input in multiple chunks and route
    through `ctx.alloc()` to make allocator/DoS assertions bite.
